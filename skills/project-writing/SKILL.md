# Scrittura di un progetto

1. Ispeziona i file esistenti.
2. Scrivi un piano breve in `/workspace/plan.md`.
3. Implementa una modifica coerente per volta.
4. Esegui test o controlli nel sandbox Docker.
5. Registra esito e comandi in `/workspace/verification.md`.
6. Chiedi al revisore un controllo indipendente se il lavoro coinvolge più file.

Non dichiarare completato il progetto se i controlli falliscono.
